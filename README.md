# My-first-project
My first programming project
📚 Student Study Planner

A simple and beginner-friendly web application designed to help students organize their studies, manage tasks, and track their study progress.

🚀 Features

- 📚 Add and manage subjects
- ✅ Create and complete study tasks
- 📊 Track overall study progress
- 📝 Maintain study notes
- 💾 Save data using browser local storage
- 📱 Simple and responsive design
- 🎨 Clean and easy-to-use interface

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

🎯 Purpose

The main purpose of this project is to provide students with a simple digital tool for organizing their daily study activities. It also helps beginners understand how HTML, CSS, and JavaScript can be combined to create a useful real-world web application.

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in any modern web browser.
4. Start managing your study tasks.
